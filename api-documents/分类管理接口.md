# 分类管理接口

## 1. 获取分类树接口

### 接口路径
`GET /admin/category/tree`

### 接口功能
获取分类树形结构，包括主分类和子分类。

### 请求参数
无

### 响应参数

#### 成功响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，成功为 "0000" |
| `message` | `string` | 响应消息，成功为 "操作成功" |
| `data` | `array` | 分类树数据 |
| `data[].id` | `long` | 分类ID |
| `data[].name` | `string` | 分类名称 |
| `data[].categoryId` | `long` | 父分类ID，主分类为null |
| `data[].subs` | `array` | 子分类列表 |

#### 响应示例

```json
{
  "code": "0000",
  "message": "操作成功",
  "data": [
    {
      "id": 1,
      "name": "眼部训练",
      "categoryId": null,
      "subs": [
        {
          "id": 1,
          "name": "上眼",
          "categoryId": 1,
          "subs": null
        },
        {
          "id": 2,
          "name": "中眼",
          "categoryId": 1,
          "subs": null
        }
      ]
    }
  ]
}
```

## 2. 批量保存分类接口

### 接口路径
`POST /admin/category/saveBatch`

### 接口功能
批量保存分类和子分类信息。

### 请求参数

#### 请求体

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `categories` | `array` | 是 | 分类列表 |
| `categories[].id` | `long` | 否 | 分类ID，新增时为null |
| `categories[].name` | `string` | 是 | 分类名称 |
| `categories[].subs` | `array` | 否 | 子分类列表 |
| `categories[].subs[].id` | `long` | 否 | 子分类ID，新增时为null |
| `categories[].subs[].name` | `string` | 是 | 子分类名称 |

#### 请求示例

```json
{
  "categories": [
    {
      "id": 1,
      "name": "眼部训练",
      "subs": [
        {
          "id": 1,
          "name": "上眼"
        },
        {
          "id": 2,
          "name": "中眼"
        }
      ]
    }
  ]
}
```

### 响应参数

#### 成功响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，成功为 "0000" |
| `message` | `string` | 响应消息，成功为 "批量保存成功" |
| `data` | `null` | 数据为null |

## 3. 删除分类接口

### 接口路径
`DELETE /admin/category/{id}`

### 接口功能
删除分类或子分类。

### 请求参数

#### 路径参数

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `id` | `long` | 是 | 分类或子分类ID |

#### 查询参数

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `isSub` | `boolean` | 是 | 是否为子分类 |

### 响应参数

#### 成功响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，成功为 "0000" |
| `message` | `string` | 响应消息，成功为 "删除成功" |
| `data` | `null` | 数据为null |

#### 失败响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，失败为非 "0000" |
| `message` | `string` | 错误消息，如 "该部位下仍有子项，请先清空子项再删除大项" |
| `data` | `null` | 数据为null |
