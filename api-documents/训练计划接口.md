# 训练计划接口

## 接口信息

### 接口路径
`GET /api/get/planToday`

### 接口功能
获取用户今日的训练计划，包括视频列表和相关信息。

## 请求参数

### 请求方式
`GET`

### 请求参数说明

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `userId` | `long` | 是 | 用户ID |

### 请求示例

```http
GET /api/get/planToday?userId=1 HTTP/1.1
Host: localhost:8080
Content-Type: application/json
```

## 响应参数

### 响应格式
`application/json`

### 成功响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，成功为 "0000" |
| `message` | `string` | 响应消息，成功为 "操作成功" |
| `data` | `object` | 今日计划数据对象 |
| `data.planId` | `long` | 计划ID |
| `data.planDate` | `string` | 计划日期 |
| `data.videos` | `array` | 视频列表 |
| `data.videos[].id` | `long` | 视频ID |
| `data.videos[].title` | `string` | 视频标题 |
| `data.videos[].videoUrl` | `string` | 视频路径 |
| `data.videos[].coverUrl` | `string` | 封面图路径 |
| `data.videos[].author` | `string` | 视频作者 |
| `data.videos[].level` | `string` | 难度等级 |

### 失败响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，失败为非 "0000" |
| `message` | `string` | 错误消息 |
| `data` | `null` | 数据为null |

### 响应示例

#### 成功响应

```json
{
  "code": "0000",
  "message": "操作成功",
  "data": {
    "planId": 1,
    "planDate": "2026-02-09",
    "videos": [
      {
        "id": 1,
        "title": "眼部训练视频",
        "videoUrl": "videos/a1b2c3d4e5f6.mp4",
        "coverUrl": "covers/a1b2c3d4e5f6.jpg",
        "author": "张教练",
        "level": "初级"
      }
    ]
  }
}
```

#### 失败响应

```json
{
  "code": "9999",
  "message": "获取今日计划失败",
  "data": null
}
```

## 代码实现

### Controller层
- `TrainingPlanController.java`：处理训练计划请求

### Service层
- `YqlTrainingPlanService.java`：训练计划服务接口
- `YqlTrainingPlanServiceImpl.java`：训练计划服务实现

## 注意事项
- `userId` 必须是已存在的用户ID
- 接口会根据当前服务器日期获取对应日期的训练计划
- 返回的视频列表会根据细分部位进行过滤
