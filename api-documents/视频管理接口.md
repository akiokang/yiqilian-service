# 视频管理接口

## 1. 分页查询视频列表接口

### 接口路径
`GET /admin/video/page`

### 接口功能
分页查询视频列表，支持按细分部位过滤。

### 请求参数

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `current` | `int` | 是 | 当前页码 |
| `size` | `int` | 是 | 每页大小 |
| `subCategoryId` | `long` | 否 | 细分部位ID，用于过滤 |

### 响应参数

#### 成功响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，成功为 "0000" |
| `message` | `string` | 响应消息，成功为 "操作成功" |
| `data` | `object` | 分页数据 |
| `data.records` | `array` | 视频列表 |
| `data.total` | `number` | 总记录数 |
| `data.size` | `number` | 每页大小 |
| `data.current` | `number` | 当前页码 |
| `data.pages` | `number` | 总页数 |

## 2. 保存视频接口

### 接口路径
`POST /admin/video/save`

### 接口功能
保存视频信息，包括视频标题、描述、作者等。

### 请求参数

#### 请求体

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `id` | `long` | 否 | 视频ID，新增时为null |
| `subCategoryId` | `long` | 是 | 细分部位ID |
| `title` | `string` | 是 | 视频标题 |
| `description` | `string` | 是 | 视频描述 |
| `author` | `string` | 是 | 视频作者 |
| `coverUrl` | `string` | 否 | 封面图路径 |
| `videoUrl` | `string` | 是 | 视频路径 |
| `level` | `string` | 是 | 难度等级 |

#### 请求示例

```json
{
  "subCategoryId": 1,
  "title": "眼部训练视频",
  "description": "这是一个眼部训练视频",
  "author": "张教练",
  "coverUrl": "covers/a1b2c3d4e5f6.jpg",
  "videoUrl": "videos/a1b2c3d4e5f6.mp4",
  "level": "初级"
}
```

### 响应参数

#### 成功响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，成功为 "0000" |
| `message` | `string` | 响应消息，成功为 "视频发布成功" |
| `data` | `null` | 数据为null |

## 4. 上传视频接口

### 接口路径
`POST /admin/video/upload`

### 接口功能
上传视频文件和视频信息，支持同时上传视频封面图。

### 请求参数

#### 请求方式
`POST`，`Content-Type: multipart/form-data`

#### 表单参数

| 参数名 | 类型 | 是否必填 | 描述 |
| :--- | :--- | :--- | :--- |
| `file` | `file` | 是 | 视频文件 |
| `coverFile` | `file` | 否 | 视频封面图文件 |
| `subCategoryId` | `long` | 是 | 细分部位ID |
| `title` | `string` | 是 | 视频标题 |
| `description` | `string` | 是 | 视频描述 |
| `author` | `string` | 是 | 视频作者 |
| `level` | `string` | 是 | 难度等级 |

### 响应参数

#### 成功响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，成功为 "0000" |
| `message` | `string` | 响应消息，成功为 "操作成功" |
| `data` | `object` | 视频信息对象 |
| `data.id` | `long` | 视频ID |
| `data.subCategoryId` | `long` | 细分部位ID |
| `data.title` | `string` | 视频标题 |
| `data.description` | `string` | 视频描述 |
| `data.author` | `string` | 视频作者 |
| `data.coverUrl` | `string` | 封面图路径 |
| `data.videoUrl` | `string` | 视频路径 |
| `data.level` | `string` | 难度等级 |
| `data.createTime` | `string` | 创建时间 |
| `data.publishTime` | `string` | 发布时间 |

#### 失败响应

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `code` | `string` | 响应码，失败为非 "0000" |
| `message` | `string` | 错误消息，如 "视频上传失败：文件大小超过限制" |
| `data` | `null` | 数据为null |
