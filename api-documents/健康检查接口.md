# 健康检查接口

## 接口信息

### 接口路径
`GET /health/check`

### 接口功能
检查服务是否正常运行，返回服务状态信息。

## 请求参数

### 请求方式
`GET`

### 请求参数说明
无

### 请求示例

```http
GET /health/check HTTP/1.1
Host: localhost:8080
Content-Type: application/json
```

## 响应参数

### 响应格式
`application/json`

### 响应字段说明

| 参数名 | 类型 | 描述 |
| :--- | :--- | :--- |
| `status` | `string` | 服务状态，正常为 "UP" |
| `message` | `string` | 服务状态描述 |
| `timestamp` | `number` | 响应时间戳 |

### 响应示例

```json
{
  "status": "UP",
  "message": "Service is running normally.",
  "timestamp": 1770635424118
}
```

## 代码实现

### Controller层
- `HealthCheckController.java`：处理健康检查请求

### 注意事项
- 该接口用于监控服务状态
- 无需认证即可访问
- 响应时间应较短，用于快速判断服务是否可用
